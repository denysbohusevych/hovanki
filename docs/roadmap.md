# Roadmap

Что уже есть в каркасе и что осталось по [ADR 0001](adr/0001-stack.md).

## Уже работает

**`:shared`**
- Протокол (DTO, `ApiRoutes`, `protocolJson`), общий для клиента и сервера.
- TOTP-коды находки: свои SHA-1/HMAC-SHA1 на чистом Kotlin, сверены с JDK; формат QR-строки `CatchCodePayload`.
- Расписание сужающейся зоны (`ZoneSchedule.stateAt`), гео-математика.
- Правила GPS: фильтр подмены и невозможных скоростей (`LocationTrack`), решения только по нескольким точкам с accuracy ≤ 20 м, проверка зоны с запасом (`ZoneRules`), дистанция находки с учётом accuracy (`CatchRules`).
- Тесты в `commonTest` гоняются на JVM и на iOS-симуляторе.

**`:server`**
- Создание игры, вход по join-коду, старт с выбором ищущих, фазы LOBBY → HIDING → SEEKING → FINISHED по таймерам.
- Синхронизация позиций и снапшот, отфильтрованный под зрителя; раскрытия `OUT_OF_ZONE`, `MOCK_LOCATION`, `STALE_SIGNAL`.
- Выход за зону: предупреждение, таймер, выбывание.
- Находка: заявка с проверкой GPS → код TOTP (5 попыток) → автоподтверждение по таймауту → спор → голосование / правило по умолчанию.
- Хранение в памяти и удаление игр после окончания или простоя (`GameJanitor`).

**Клиент (`:clientCore`, `:composeApp`, `:androidApp`, `iosApp`)**
- Общий Compose UI для Android и iOS, Koin, навигация по состоянию.
- `GameApi` на Ktor и `GameConnection` (HTTP-опрос), `ServerClock`.
- Геолокация (FusedLocationProvider / CLLocationManager) и работа в фоне (foreground service / фоновый режим location).
- Показ кода находки и ручной ввод 4 цифр; схематичная зона на Canvas (`ZoneRadar`) вместо карты.
- Строки интерфейса на английском, украинском и русском (Compose resources), тексты системных разрешений iOS — тоже.
- Версия, номер сборки и commit внизу главного экрана; адрес сервера по умолчанию задаётся при сборке (`hovanki.serverUrl`).

**Инфраструктура**
- CI: ktlint, тесты, сборка Android и iOS. Релиз: подписанные APK/AAB, образ сервера в GHCR, GitHub Release. Dependabot.
- Тестовые сборки на телефоны ([ci-cd.md](ci-cd.md#как-поставить-сборку-на-телефон)): каждый push в `main` — подписанный APK на pre-release `preview` (обновления через Obtainium) и загрузка в TestFlight; сервер с компьютера — через Cloudflare Quick Tunnel. Подпись и загрузка заработают, когда в репозитории появятся секреты; до этого job'ы собирают без подписи и пишут, чего не хватает.
- E2E-тесты ([e2e.md](e2e.md)): headless-боты на коде `:clientCore` играют партии против сервера на каждый push; приложение на Android-эмуляторах и iOS-симуляторе вместе с ботами — каждую ночь.

## TODO

### До первого теста на улице

- [ ] **Карта**: MapLibre через maplibre-compose, выбор провайдера векторных тайлов на базе OSM (лимиты, цена, атрибуция).
- [ ] **QR**: отрисовка QR с `CatchCodePayload` на экране прячущегося; сканер — CameraX + ML Kit (Android), AVFoundation (iOS) вместо заглушки `CatchCodeScanner`.
- [ ] **Согласие на геолокацию** (GDPR): экран с объяснением до системного запроса разрешений, ссылка на политику приватности.
- [ ] **Создание игры**: выбор центра и радиуса зоны на карте; подсказка, если зона сильно застроена.
- [ ] **Фон на реальных телефонах**: e2e проверяет фоновую отправку точек только на эмуляторе и симуляторе; проверить руками на iPhone и Android с агрессивным энергосбережением (Xiaomi, Samsung). Заодно — потерянные тапы по кнопкам Compose, замеченные на iOS-симуляторе ([e2e.md](e2e.md#известные-ограничения)).
- [ ] **Батарея**: настраиваемый интервал обновления координат (сейчас синхронизация раз в `syncIntervalSeconds`), замер расхода на реальных телефонах в фоне.
- [ ] **Восстановление сессии после перезапуска приложения**: сейчас сессия только в памяти, и убитое системой приложение не может вернуться в идущую игру (повторный вход отвечает `WRONG_STATE`). Нужны сохранённый токен и эндпоинт или `sync` для возврата; e2e-сценарии `RestartTest` и `restart` фиксируют текущее поведение и должны измениться вместе с ним.
- [ ] **Секреты для тестовых сборок**: Android keystore и iOS (Apple Developer Program, сертификат, профиль, API key) — списки в [ci-cd.md](ci-cd.md#секреты-для-подписи-android) и [ci-cd.md](ci-cd.md#что-сделать-в-apple-developer-и-app-store-connect). Первый запуск с секретами проверит подпись и загрузку в TestFlight, которые без них не проверить.
- [ ] **Деплой сервера**: хостинг, домен, TLS. Затем `hovanki.serverUrl` в `gradle.properties` — и тестовые сборки стартуют с этим адресом.
- [ ] **Настройки клиента**: сохранять адрес сервера и имя игрока между запусками (например, multiplatform-settings / DataStore). С туннелем особенно нужно: длинный случайный адрес сейчас вводится заново после каждого перезапуска приложения.

### Честная игра

- [ ] **«Игрок в здании»**: контуры зданий из OSM + ухудшение accuracy; на Android дополнительно `GnssStatus`. Раскрытие ищущим, если похоже на здание дольше минуты (новая причина видимости — с учётом совместимости протокола, см. [architecture.md](architecture.md#совместимость-протокола)).
- [ ] **Разбор после игры**: треки всех игроков на карте. Сервер сейчас держит только последние 5 минут трека — нужно хранить трек до конца `finished-retention` и отдать его отдельным эндпоинтом.
- [ ] **Судья-наблюдатель**: роль, которая видит всех и разбирает споры.

### После MVP

- [ ] **BLE-близость** через Kable: вещание и сканирование, сглаживание RSSI в `:shared` («горячо / тепло / холодно»), fallback на GPS для связки «iPhone прячется, Android ищет»; автоподтверждение находки по BLE.
- [ ] **WebSocket или SSE** за интерфейсом `GameConnection`, когда появятся мгновенные функции (чат, живое отслеживание).
- [ ] **Хранилище и масштабирование**: `GameRegistry` на Redis/Postgres, несколько экземпляров сервера (общее хранилище с блокировкой игры или маршрутизация по `gameId`), игры переживают деплой.
- [ ] **Публикация**: App Store (ревью сборки из TestFlight, анкета App Privacy) и Google Play из CI (см. [ci-cd.md](ci-cd.md#google-play-позже)).
- [ ] **Репутация для публичных лобби**: жалобы от разных игроков из разных игр снижают рейтинг, затем временный запрет.
- [ ] **Локализация**: строки уже в Compose Multiplatform resources (en, uk, ru). Осталось вычитать переводы и выбрать язык по умолчанию.
