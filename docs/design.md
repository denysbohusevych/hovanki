# Дизайн: стиль «Дофамин»

Спецификация интерфейса Hovanki: цвета, шрифты, форма, компоненты, экраны, анимации и вибрация, и план, как перевести на это текущий Compose UI. Почему именно этот стиль — [ADR 0006](adr/0006-visual-style.md).

**Статус:** спецификация принята, код ещё не переделан (см. [план](#9-план-реализации)).

## Макеты

Холст с макетами: <https://claude.ai/artifact/XcwrmaKs64fYfEHhkXRQmQ> (приватный: доступ даёт владелец через Share). Макеты — HTML, не Kotlin; размеры в них — CSS px, в приложении это dp один к одному.

Что на холсте:
- ряд **«Выбрано: „Дофамин“, светлый»** — источник правды: палитра, главная, лобби, игра прячущегося и ищущего, код находки, итоги и живое демо анимаций зоны;
- ряды выше — первые варианты в спокойном стиле. Из них берём **компоновку** экранов, которых нет в дофаминовом ряду (согласие на геолокацию, создание игры, находка у ищущего, голосование), и перекрашиваем по этой спецификации.

## 1. Принципы

1. **Ярко, но читается на солнце.** Только светлая тема. Фон светлый, текст почти чёрный, яркие цвета — плашками, а не тонкими линиями.
2. **Одной рукой на бегу.** Цели нажатия не меньше 48 dp, главное действие экрана — внизу, одно на экран.
3. **Цвет — не единственный сигнал.** Роль, состояние зоны, тревога всегда дублируются текстом, иконкой или формой.
4. **Прячущийся не шумит.** Никаких звуков у прячущегося; всё важное — вибрацией.
5. **Движение объясняет игру.** Постоянно двигается только то, что требует внимания прямо сейчас (зона перед сужением, тревога, раскрытый игрок). В спокойном состоянии экран неподвижен — это и батарея, и внимание.

### Правила контраста

1. Салатовый — **фон под чёрным текстом** или кольцо **с чёрной обводкой**. Салатовый текст или тонкая линия на белом не читаются (контраст 1,1).
2. На оранжевом и розовом — чёрный текст; на фиолетовом — белый. Белый на оранжевом не проходит (3,1).
3. Мелкий текст — не светлее `ink3`. Всё проверять по WCAG AA: 4,5 для текста, 3 для крупного и иконок.
4. Роли различаются не только оттенком, но и светлотой (оранжевый светлее фиолетового), и всегда подписаны: «Ищет» / «Прячется», своя иконка.

### Смысл цветов

- **Салатовый** — «главное, можно, безопасно». На экране одна салатовая кнопка — та, которую нажимают чаще всего.
- **Фиолетовый** — прячущиеся. **Оранжевый** — ищущие. Для прячущегося оранжевый заодно значит «тебя увидят ищущие» — поэтому тревога «за зоной» оранжевая.
- **Розовый** — «здесь нельзя быть»: здание, полоса зоны, которая скоро исчезнет, движущееся кольцо, тревога «в здании». Во вне игровых экранах — награды и счётчики непрочитанного.
- **Чёрный** — каркас: текст, обводки, тени, капсулы HUD поверх карты.

### Material 3

Material-компоненты, которые остаются (поля ввода, диалоги, снекбары), получают схему:

| Роль M3 | Токен |
|---|---|
| `primary` / `onPrimary` | `lime` / `ink` |
| `primaryContainer` / `onPrimaryContainer` | `lime` / `ink` |
| `secondary` / `onSecondary` | `violet` / белый |
| `tertiary` / `onTertiary` | `orange` / `ink` |
| `error` / `onError` | `pinkInk` / белый |
| `background`, `surface` / `onBackground`, `onSurface` | `cream`, `paper` / `ink` |
| `surfaceVariant` / `onSurfaceVariant` | `line` / `ink2` |
| `outline` | `ink` |

Всё, чего нет в M3 (роли, `pink`, `stale`, карта), — в своём `HovankiColors` через `CompositionLocal`.

### Карта

Основа — стиль OpenFreeMap **positron** (светло-серый, как сейчас): на нейтральном фоне яркие слои видны лучше всего. Слои поверх:

| Слой | Вид |
|---|---|
| Снаружи зоны | затемнение `ink` 18 % (полигон «мир с дыркой»): снаружи «опасно» |
| Кольцо зоны | обводка `ink` 8 dp + сердцевина 4 dp (`lime` в покое, `pink` при сужении) |
| Следующая зона | `ink` 2 dp пунктиром 8/5 |
| Исчезающая полоса | между текущим и следующим кругом, `pink` 14–50 %, только перед и во время сужения |
| Запретные здания | `pink` 30 % + граница `pink` 1,5 dp; штриховка, если `fill-pattern` заработает в maplibre-compose. Проходы — белым, как сейчас |
| Своя точка | 14 dp цвета роли, белая обводка 3 dp, ореол точности цвета роли 20 % |
| Свои (команда) | 24 dp `orange`, обводка `ink` 2,5 dp, инициал |
| Раскрытый прячущийся | 24 dp `violet`, белая обводка, «пинг» (см. анимации), подпись «Оля · за зоной · 12 с» на чёрной плашке |
| Нет сигнала | `stale`, пунктирная белая обводка, прозрачность падает со временем |

## 3. Шрифты

- **Unbounded** (700, 800) — заголовки, таймеры, коды, все крупные цифры.
- **Manrope** (500–800) — весь остальной текст.

Оба под лицензией OFL, с кириллицей; при подключении проверить украинские ґ, є, ї, і. Файлы — в `composeApp/src/commonMain/composeResources/font/`, только нужные начертания (около 0,5 МБ вместе).

| Стиль | Шрифт | Размер / вес | Где |
|---|---|---|---|
| `display` | Unbounded | 30 / 800, строка 1,1 | «Привет, Лена!», «Ищущие нашли всех!» |
| `title` | Unbounded | 22–26 / 800 | заголовки экранов и карточек |
| `timer` | Unbounded | 28 / 800 | HUD |
| `code` | Unbounded | 32–34 / 800 | цифры кода, код лобби |
| `section` | Manrope | 16–17 / 800 | заголовки разделов |
| `body` | Manrope | 15 / 600 | основной текст |
| `caption` | Manrope | 13 / 600 | подписи |
| `label` | Manrope | 10–12 / 800, разрядка 1 | КАПСОМ в HUD и на бейджах |

У Unbounded цифры разной ширины: таймеры и счётчики ставим в поле фиксированной ширины, чтобы текст не дёргался каждую секунду. Системный масштаб шрифта поддерживаем, но в HUD ограничиваем 1,3×, чтобы капсулы не разъезжались.

## 4. Форма и глубина

- **Скругления:** 12 dp — чипы; 16 — поля, плитки, малые кнопки; 20 — карточки; 24–28 — крупные карточки и шторки; полные — капсулы и круглые кнопки.
- **Обводка** 2,5 dp `ink` у «осязаемых» элементов: кнопки, карточки-действия, поля ввода, плитки кода; у аватаров — 2 dp.
- **Жёсткая тень**: смещение 4–6 dp вниз-вправо, цвет `ink`, без размытия. Только у главной кнопки, крупных карточек-действий и выбранного элемента — не больше двух на экран. Обычные карточки — без тени.
- **Нажатие**: элемент сдвигается на величину тени, тень исчезает (80 мс), при отпускании возвращается пружиной. Это главный «тактильный» эффект стиля.
- **Сетка** 4 dp: отступы 4 / 8 / 12 / 16 / 20 / 24; поля экрана 16–20 dp.

## 7. Анимации и отклик

### 7.1 Токены движения

| Токен | Длительность | Кривая (Compose) | Где |
|---|---|---|---|
| `press` | 80 мс вниз, пружина вверх | `tween(80)`, затем `spring(0.5f, StiffnessMedium)` | нажатие кнопок |
| `fast` | 150 мс | `FastOutSlowInEasing` | смена цвета, появление бейджа |
| `base` | 250 мс | `FastOutSlowInEasing` | смена состояния, сворачивание |
| `screen` | 320 мс | вход `LinearOutSlowInEasing`, выход `FastOutLinearInEasing` | полноэкранные слои, шторки |
| `pop` | ~400 мс | `spring(dampingRatio = 0.5f, stiffness = StiffnessMediumLow)` | «выскакивание»: награды, «Сузилась», новый игрок |
| `celebrate` | 1–1,5 с | своя, частицы на `Canvas` | находка засчитана |

Экраны: вкладки — плавная смена (`fade`, `base`), полноэкранные слои (находка, код, чат) — выезд снизу (`screen`), возврат — обратно.

### 7.2 Зона — главная анимация

Демо «Зона: анимации» на холсте проигрывает все этапы по кругу.

| Этап | Когда | Кольцо | Полоса и пунктир | HUD | Вибрация |
|---|---|---|---|---|---|
| Спокойно | до сужения больше минуты | `lime` + чёрная обводка, неподвижно | пунктир следующей зоны, неподвижно | «сужение через 2:40», кольцо-таймер `lime` | — |
| Скоро | последние 60 с (или вся пауза, если она короче) | как в покое | полоса, которая исчезнет, мигает `pink` 14↔50 %, период 2 с; пунктир «бежит» (сдвиг штриха) | число `pink` | одна короткая в начале этапа |
| Последние 10 с | 10 с до сужения | как в покое | мигание раз в секунду, в такт отсчёту | число `pink` «тикает» (масштаб 1→1,15→1 каждую секунду) | короткие на 3, 2, 1 |
| Сужается | идёт сужение | сердцевина плавно становится `pink` (250 мс) и едет к новому кругу; от кольца расходится пульс раз в 1,6 с (ширина 4→34 dp, прозрачность 0,8→0) | полоса `pink` 30 % без мигания, сжимается вместе с кольцом | «зона сужается 0:45» `pink` | — |
| Сузилась | 1,5 с после конца сужения | «щелчок»: обводка 8→20→8 dp (`pop`), сердцевина обратно `lime` | полоса гаснет (250 мс), новый пунктир проявляется | счётчик до следующего «выскакивает» | одна средняя |
| Финал | стадий больше нет | `lime`, неподвижно | пунктира нет | «ФИНАЛЬНАЯ ЗОНА» | — |

Устройство:
- Этап — чистая функция от расписания зоны и времени: `zoneCue(schedule, elapsedMillis)` в `:clientCore` (это подсказка интерфейса, не правило игры, поэтому не в `:shared`), с тестами в `commonTest` на границы этапов. Время — только `ServerClock`.
- Само кольцо уже считается `ZoneSchedule.stateAt(...)`. Сужение медленное (круг 300 → 150 м за 2 минуты — меньше 1 dp в секунду на экране), поэтому геометрию на карте достаточно обновлять 2–4 раза в секунду: «движение» передают цвет и пульс, а не частота кадров.
- Пульс, мигание и «бегущий» пунктир — анимированные свойства слоёв MapLibre (прозрачность, ширина, сдвиг штриха). Если на слабых Android это будет дёргаться — рисуем эффекты на `Canvas` поверх карты через проекцию камеры, а в слоях остаётся неподвижное кольцо. Решаем на первом шаге этапа 4.

### 7.3 Игроки на карте

- **Плавное движение.** Точки приходят раз в несколько секунд; маркер едет к новой позиции за 800 мс, а не прыгает. Если скачок больше 150 м (переподключение), — без анимации.
- **Своя точка:** ореол точности плавно меняет размер (`base`).
- **Раскрытие прячущегося** у ищущих: маркер появляется с «пингом» — два расходящихся кольца `violet` (600 мс), затем одно кольцо раз в 3 с, пока игрок раскрыт. Подпись показывает возраст точки («12 с»).
- **Нет сигнала:** маркер `stale` с пунктирной обводкой, прозрачность падает с 1 до 0,5 по мере старения точки.
- **Свои:** появляются без эффектов — их видно всегда, внимания они не требуют.

### 7.4 Тревоги прячущегося

| Тревога | Экран | Ритм | Вибрация |
|---|---|---|---|
| За зоной | `EdgeVignette` оранжевая + `AlertPill` «ВЕРНИСЬ В ЗОНУ 0:42» + стрелка у края экрана в сторону зоны | виньетка пульсирует 1 раз в секунду, в последние 10 с — 2 раза | длинная при входе в тревогу, затем короткая каждые 10 с, в последние 5 с — каждую секунду |
| В здании | `EdgeVignette` розовая + «ВЫЙДИ ИЗ ЗДАНИЯ 0:48» | 1 раз в 2 с | длинная при входе, затем каждые 15 с |
| Вернулся | виньетка гаснет (250 мс), тост «Ты в зоне» с салатовой иконкой | — | одна короткая |

### 7.5 Фазы игры

- **Старт** (лобби → прятки): полноэкранный отсчёт «3-2-1» (`pop` на каждой цифре), затем у прячущихся «Прячься!» и таймер, у ищущих — экран «Жди, не подглядывай» с крупным таймером.
- **Начало поиска:** у ищущих — вспышка «Ищи!» на салатовом (1 с) и вибрация; у прячущихся — розовая плашка «Ищущие вышли!» сверху (3 с) и вибрация.
- **Конец игры:** переход в итоги (см. 7.8).

### 7.6 Находка

- **«Нашёл!»:** нажатие с `press`, выезд слоя находки (`screen`).
- **Код принят:** у ищущего — салатовая вспышка и конфетти из кругов и волн цветов палитры (`celebrate`) + вибрация «успех»; у прячущегося — мягкий фиолетовый экран «Тебя нашли» без конфетти.
- **Неверный код:** плитки трясутся по горизонтали (3 колебания, 300 мс) + вибрация «ошибка»; под плитками — «осталось попыток: 3».
- **Смена кода у прячущегося:** цифры «перелистываются» вверх по одной с задержкой 40 мс (250 мс каждая), QR меняется через растворение (150 мс). Кольцо «новый код через» и полоса «засчитается само через» идут непрерывно, без скачков.
- **Спор:** шторка голосования выезжает у всех, кроме спорящих; после голоса кнопки сворачиваются в «Голос принят».

### 7.7 Меню и лобби

- Новый игрок в лобби: строка въезжает снизу, аватар «выскакивает» (`pop`); вибрация у хоста — нет (не отвлекаем).
- Смена роли: пилюля меняет цвет (`fast`) с лёгким `pop`.
- «Случайно»: иконка кубика качается, роли 300 мс мелькают, затем встают на место.
- Код лобби скопирован: тост «Код скопирован».
- Вкладки: салатовая пилюля переезжает к выбранной вкладке (`base`).

### 7.8 Итоги

Заголовок «выскакивает» (`pop`), числа времени отсчитываются вверх (600 мс), карточки наград падают сверху по очереди с задержкой 80 мс. Когда появятся треки — линии прорисовываются за 1,5 с, ползунок времени начинает с конца.

### 7.9 Вибрация и звук

| Событие | Кто | Вибрация |
|---|---|---|
| Нажатие главных кнопок | все | лёгкая (системная `ContextClick`/`VirtualKey`) |
| Зона: скоро / 3-2-1 / сузилась | все | короткая / три коротких / средняя |
| Начало поиска | все | двойная |
| За зоной, в здании | прячущийся | см. 7.4 |
| На тебя подали заявку («Покажи код!») | прячущийся | длинная, повтор через 10 с, если экран не открыт |
| Код принят | ищущий / прячущийся | «успех» / одна длинная |
| Неверный код | ищущий | «ошибка» |

- **Звуков нет** по умолчанию ни у кого; у прячущегося звуков нет никогда — звук выдаёт укрытие.
- Тревоги, пока телефон в кармане с выключенным экраном, должны вибрировать из фона: Android — уведомление с вибрацией через канал foreground service, iOS — локальное уведомление (нужно разрешение на уведомления). Это часть `BackgroundTracker`.

### 7.10 Батарея и «уменьшить движение»

- Анимации идут, только пока экран включён и приложение на переднем плане (Compose сам останавливается в фоне). Бесконечные анимации — только в этапах, которые их требуют (скоро сужение, сужение, тревога, раскрытый игрок).
- Системная настройка «уменьшить движение» (Android: масштаб анимаций 0; iOS: Reduce Motion): без пульсов, мигания, «пингов», конфетти и отсчёта «3-2-1»; смены цвета, плавное движение кольца и маркеров и вибрация остаются.

## 8. Доступность

- Контраст — по правилам из раздела 2; цели нажатия ≥ 48 dp.
- Иконки без текста — с `contentDescription`; бейджи счётчиков читаются вместе с кнопкой («Чат, 2 новых»).
- Роль и состояние зоны всегда есть текстом (бейдж роли, подпись в HUD), не только цветом.
- Масштаб шрифта: экраны меню растут свободно, HUD — до 1,3×.
- Тревоги — `LiveRegion`, чтобы экранный диктор их зачитал.

## 9. План реализации

Каждый этап — отдельный PR, после каждого приложение работает целиком. UI-изменения по правилам репозитория проверяются `./gradlew :e2e:devices` на эмуляторах или ручным запуском `nightly.yml` с `suite=devices` на ветке; скриншоты фаз — в отчёте `e2e/build/reports/devices/`. Видимое игроку — запись в `docs/devlog.md`.

1. **Основа.**
   - `ui/theme/`: `Colors.kt` (`HovankiColors` + схема M3), `Type.kt` (Unbounded, Manrope), `Shapes.kt`, `Motion.kt` (токены из 7.1).
   - Шрифты в `composeResources/font/`.
   - Убрать тёмную схему и `isSystemInDarkTheme()` из `HovankiTheme`.
   - `Modifier.hardShadow(...)` и `Modifier.pressable(...)` (сдвиг на тень при нажатии).
   - Результат: всё приложение уже в новых цветах и шрифтах через M3, без правки экранов.
2. **Компоненты.**
   - Всё из раздела 5 в `ui/common/`.
   - `FloatingTabBar` вместо `NavigationBar` в `MainScreen`.
   - Кнопки на всех экранах заменить на `PopButton`, тест-теги перенести.
3. **Экраны вне игры.**
   - Вход, главная, друзья, группы, профиль, лобби (`RolePill`, «Случайно»), итоги (без треков и наград), чат, подтверждение email.
   - Экран согласия на геолокацию (закрывает пункт roadmap «Согласие на геолокацию»).
4. **Игра.**
   - Первый шаг — проверка, выдерживают ли слои MapLibre пульс и мигание (7.2), или эффекты уходят в `Canvas`.
   - Затем по порядку:
     - цвета слоёв карты и кольцо с обводкой;
     - затемнение снаружи;
     - `zoneCue` в `:clientCore` с тестами;
     - анимации зоны;
     - плавные маркеры и «пинг» раскрытия;
     - HUD-раскладка `GameScreen`;
     - тревоги с виньеткой;
     - полноэкранные слои находки у ищущего и прячущегося;
     - шторка голосования.
5. **Отклик.**
   - Платформенный сервис `Haptics` (интерфейс в `commonMain`; Android `Vibrator`, iOS `UIImpactFeedbackGenerator`/`UINotificationFeedbackGenerator`; фейк для тестов) — по рецепту «Новый платформенный сервис» в [architecture.md](architecture.md).
   - Яркость и «не гасить экран» на экране кода.
   - Признак «уменьшить движение» (`expect`/`actual`).
   - Фоновая вибрация тревог через `BackgroundTracker`.
6. **Вместе с фичами, которых ещё нет** (своими PR, когда до них дойдёт roadmap):
   - QR на экране прячущегося и сканер;
   - находка одним сканом (в `CatchCodePayload` уже есть ID игрока);
   - создание игры с выбором места и радиуса на карте;
   - треки в итогах (серверу нужно хранить трек до конца игры);
   - награды и «Прошлая игра» на главной (статистика игр);
   - вход в лобби по QR.
