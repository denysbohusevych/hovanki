# ADR 0022. Рейтинг города: город выбирает сам игрок

- **Статус:** Accepted (сервер, протокол, `:clientCore` и экраны в коде; на телефонах ещё не пробовали)
- **Дата:** 2026-10-07
- **Автор:** Denys Bohusevych (черновик — Claude Code)
- **Дополняет:** [ADR 0020](0020-leaderboard.md) (рейтинг, раздел 3 «„Друзья“ вместо „Киева“»), [ADR 0004](0004-accounts-friends-chat.md) (аккаунты, сроки хранения), [ADR 0007](0007-game-history-and-routes.md) (история игр)

## Контекст

В макете у рейтинга вкладки «Остання гра / Київ / Світ». В ADR 0020 «Київ» заменили на «Друзі»: чтобы считать рейтинг города, надо знать город игрока, а сервер его не хранит, и решение о новом персональном данном отложили.

Город можно было бы взять из игр: где была зона. Но место игры — данные о местоположении, их мы держим только в памяти игры (GDPR-раздел `CLAUDE.md`), а «где человек играл» по сути его маршрут по городу в масштабе недель. Это ровно то, чего мы обещаем не хранить.

## Решение коротко

| Вопрос | Решение |
|---|---|
| Откуда город | Игрок **сам** выбирает его в профиле или прямо на вкладке рейтинга. Необязательно, по умолчанию не выбран. По GPS, IP или зоне игры город **не определяем** и не подсказываем |
| Какие города | Фиксированный список `Cities.IDS` в `:shared`: областные центры вне оккупации и несколько больших городов (25 штук), id латиницей (`kyiv`, `lviv`, …). Названия — в ресурсах приложения на трёх языках. Свободного ввода нет: нечего модерировать, и «Киев/Київ/kiev» всегда один город. Новые id можно добавлять, переименовывать и удалять нельзя |
| Где хранится | Колонка `users.city` (миграция `V15`), `null` — не выбран. Живёт вместе с аккаунтом: удалил аккаунт — города нет. Отдельного срока хранения не нужно |
| Маршрут | `POST /api/v1/me/city` с `CityRequest(city)`, `null` — забыть; отвечает `UserProfile` (в нём `city`). Неизвестный id — 400 |
| Вкладка | `LeaderboardScope.CITY`: все, у кого **сейчас** тот же город, по очкам этой недели, как «Мир» — первые 50 и своя строка `me`, `nextAbove`, `rankChange`. В ответе `city`; без своего города — пустой ответ с `city = null`, приложение предлагает выбрать город |
| Прошлая неделя | Для `rankChange` — тоже по сегодняшним городам (как «Друзья» — по сегодняшнему списку друзей). Сменил город — сравнение с прошлой неделей нового города |
| Порядок вкладок | «Остання гра / Київ / Друзі / Світ»: город на втором месте, как в макете; вкладка называется городом игрока, пока город не выбран — «Місто» |

## Приватность

- **Только выбор игрока.** Город не выводится из положения телефона ни на телефоне, ни на сервере. В профиле под городом написано, зачем он и кто его видит.
- **Что видят другие.** Сам город в ответах о других игроках не передаётся. Его видно косвенно: игрок с городом попадает в рейтинг этого города, и другие игроки этого города видят там его ник и очки за неделю — то же, что и так видно во «Мире».
- **Персонал** город не видит: в админке его нет.
- **Убрать** город можно в любой момент («Не вказувати»), и игрок сразу пропадает из рейтинга города.
- Гости, забаненные и удалённые — как в ADR 0020: гостей нет, забаненных не показываем, удалённые уносят свои строки.

## Как считается

`LeaderboardService` для `CITY` читает город вызывающего (`LeaderboardRepository.cityOf`), затем те же строки `game_results`, что и для «Мира», с условием `users.city = :city`. Агрегация и правило очков те же (`LeaderboardRules`). Индекса по `users.city` нет: запрос идёт от строк `game_results` за две недели (индекс `V14`), а `users` подтягивается по ключу.

## Последствия

- Протокол обратно совместим: новое поле `UserProfile.city`, новое поле `LeaderboardResponse.city`, новое значение `LeaderboardScope.CITY` (старые приложения его не запрашивают и в ответах не получают), новый маршрут.
- Приложение: `AccountManager.setCity`, `CityPickerDialog` (`ui/common/CityPicker.kt`), строка «Місто» в профиле, вкладка города в «Рейтинге».
- Тесты: `CitiesTest` (`:shared`), `LeaderboardServiceTest` (вкладка города, без города, смена города, маршрут `/me/city`), `HttpHistoryApiTest`, e2e `LeaderboardTest`.
- Открыто: города за пределами Украины (когда появятся игроки), рейтинг города за все времена, подсказка «в твоём городе играют N человек».
