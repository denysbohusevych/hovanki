# ADR 0024. Итоги в сторис Instagram

- **Статус:** Accepted (в коде; на телефонах ещё не пробовали, iOS-часть написана без сборки)
- **Дата:** 2026-10-07
- **Автор:** Denys Bohusevych (черновик — Claude Code)
- **Дополняет:** [ADR 0006](0006-visual-style.md) (визуальный стиль), [ADR 0011](0011-spectators-and-recordings.md) (записи игр), [ADR 0020](0020-leaderboard.md) (кнопка «Поделиться» на итогах)

## Контекст

После редизайна (PR #72) на итогах есть чёрная карточка «Твой результат» и кнопка «Поделиться», которая отправляла только строку текста. Игроки хвастаются партиями в Instagram Stories: картинка там работает лучше текста и приводит новых игроков.

## Решение коротко

| Вопрос | Решение |
|---|---|
| Как выглядит | По двум макетам дизайнера (2026-10-07), 1080 × 1920 (9:16): логотип «hovanki», в углу «6 гравців · 24:13»; «Мій час у схованці» и большое время прятавшегося (или «Мої знахідки» и число находок ищущего), рядом наклонная плашка места «2 з 4»; схема пути; первая своя награда наклонной плашкой; внизу «Зіграй у хованки з нами» |
| Два варианта | **«Усі»** на чёрном: мой путь салатовым со свечением, путь того, кто меня нашёл, белым пунктиром до момента находки, остальные тонкими линиями (прячущиеся розовым, ищущие серым), легенда «я · мене знайшли: Макс · ще 4». **«Тільки я»** на салатовом: только мой путь (розовый у прячущегося, чёрный у ищущего), «старт», «тут мене знайшли: Макс» у крестика и длина пути «1,4 км». Игрок выбирает на экране предпросмотра; по умолчанию «Усі» |
| Схема, не карта | Пути — это формы относительно центра зоны, в масштабе, где влезает весь мой путь и круг зоны. Под ними **выдуманная** сетка улиц и «парк», одинаковые в каждой картинке, а не настоящая карта: по картинке нельзя узнать, где играли. Крестик — где меня нашли (конец моего пути) или где нашёл я (конец пути найденного) |
| Чего нет | Настоящей карты, улиц, адреса, города, даты и времени суток. Из чужих имён — только тот, кто меня нашёл, как в макете |
| Где рисуется | В приложении, без сервера: `StoryRenderer` (`ui/results/StoryCard.kt`) рисует на `ImageBitmap` через `CanvasDrawScope` и `TextMeasurer` шрифтами приложения; что показать — чистые `myResult()`/`story()`/`scheme()` с тестами (`StoryCardTest`), путь прорежен до 160 точек. PNG — `encodePng()` (Android `Bitmap.compress`, iOS Skia) |
| Экран | На итогах «Поделиться» стала «В сторис» (`TestTags.RESULTS_SHARE`): открывается панель предпросмотра (`StoryPanel`) с картинкой ровно такой, какая уйдёт, переключателем «Тільки я / Усі» (если путь загружен) и кнопкой «Поделиться» (`TestTags.STORY_SHARE`). Пока пути не загрузились — картинка без схемы |
| Куда уходит | `StoryShare`: если есть Instagram и в сборке есть ID приложения Meta — сразу в редактор сторис (Android: интент `com.instagram.share.ADD_TO_STORY` с картинкой фоном; iOS: картинка в pasteboard как `com.instagram.sharedSticker.backgroundImage` и `instagram-stories://share`). Иначе — системное «Поделиться» с картинкой и строкой текста |
| ID приложения Meta | Gradle-свойство `hovanki.facebookAppId` → `BuildConstants.FACEBOOK_APP_ID`, только цифры или пусто (по умолчанию пусто). С 2023 года Meta требует `source_application` = ID приложения для прямого шаринга в сторис; без него остаётся системное меню, где Instagram тоже есть |
| Android | Картинка пишется в `cache/story/` и отдаётся через свой `StoryFileProvider` (`${applicationId}.story`) из манифеста `:composeApp`, во всех сборках; свой класс, потому что два `<provider>` одного класса не сливаются с провайдером лаборатории в debug. `<queries>` на `com.instagram.android`, чтобы увидеть Instagram на Android 11+ |
| iOS | `LSApplicationQueriesSchemes` = `instagram-stories` (иначе `canOpenURL` всегда «нет»); `NSPhotoLibraryAddUsageDescription`, потому что в системном меню с картинкой есть «Сохранить изображение», а без этой строки iOS закрывает приложение |

## Почему так

- **Схема вместо карты.** Настоящая карта с путями показывает двор, где играли, а часто — где живёт игрок; сторис видят посторонние. Форма пути на выдуманной сетке передаёт то же чувство («вот как я бегал»), но место не выдаёт. Город и парк из макета не пишем: сервер их не знает, а по ним место угадывается.
- **Имя нашедшего — как в макете.** Это часть истории партии («Макс нашёл меня»), и его ник и так видят все игроки партии. Остальные игроки — только линии и число.
- **Предпросмотр.** Игрок видит ровно то, что уйдёт к подписчикам, и сам выбирает, показывать ли чужие пути.
- **Рисуем в приложении.** Сервер не знает, как игрок хочет поделиться, и не должен хранить картинки. Всё нужное уже есть на итогах: снимок игры и пути для повтора (ADR 0011).
- **Прямо в Instagram — по возможности.** Без ID Meta всё работает через системное меню; когда ID появится, достаточно передать свойство в CI.

## Что дальше

- Завести приложение в Meta for Developers и передать `hovanki.facebookAppId` в `preview.yml` и `release.yml`.
- Проверить на телефонах: Android с Instagram и без, iPhone с Instagram и без, «Сохранить изображение» на iPhone.
- Варианты картинки (наклейка поверх фото, другие фоны, без водяного знака за премиум) — после проверки и решения по монетизации (ADR 0023).
