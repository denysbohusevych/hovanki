# ADR 0024. Итоги в сторис Instagram

- **Статус:** Accepted (в коде; на телефонах ещё не пробовали, iOS-часть написана без сборки)
- **Дата:** 2026-10-07
- **Автор:** Denys Bohusevych (черновик — Claude Code)
- **Дополняет:** [ADR 0006](0006-visual-style.md) (визуальный стиль), [ADR 0011](0011-spectators-and-recordings.md) (записи игр), [ADR 0020](0020-leaderboard.md) (кнопка «Поделиться» на итогах)

## Контекст

После редизайна (PR #72) на итогах есть чёрная карточка «Твой результат» и кнопка «Поделиться», которая отправляла только строку текста. Игроки хвастаются партиями в Instagram Stories: картинка там работает лучше текста и приводит новых игроков.

## Решение коротко

| Вопрос | Решение |
|---|---|
| Что на картинке | 1080 × 1920 (9:16) на чёрном: «ХОВАНКИ», «Игра окончена · 24:13», кто победил, карточка игрока цвета его роли (инициал, ник, как прошло, большое число: сколько продержался прячущийся или сколько нашёл ищущий), счёт партии (найдены / не найдены / выбыли), до двух **своих** наград (сколько помещается), подпись «Хованки · прятки на улицах города» |
| Чего нет | Карты, зоны, треков, адреса, даты и времени суток, чужих имён и ников. Картинка уходит из игры ко всем подписчикам игрока: место игры и чужие ники туда не попадают |
| Где рисуется | В приложении, без сервера: `StoryRenderer` (`ui/results/StoryCard.kt`) рисует на `ImageBitmap` через `CanvasDrawScope` и `TextMeasurer` шрифтами приложения; что показать — чистые `myResult()`/`story()` с тестами (`StoryCardTest`). PNG — `encodePng()` (Android `Bitmap.compress`, iOS Skia) |
| Куда уходит | `StoryShare`: если есть Instagram и в сборке есть ID приложения Meta — сразу в редактор сторис (Android: интент `com.instagram.share.ADD_TO_STORY` с картинкой фоном; iOS: картинка в pasteboard как `com.instagram.sharedSticker.backgroundImage` и `instagram-stories://share`). Иначе — системное «Поделиться» с картинкой и прежней строкой текста |
| ID приложения Meta | Gradle-свойство `hovanki.facebookAppId` → `BuildConstants.FACEBOOK_APP_ID`, только цифры или пусто (по умолчанию пусто). С 2023 года Meta требует `source_application` = ID приложения для прямого шаринга в сторис; без него остаётся системное меню, где Instagram тоже есть |
| Кнопка | На итогах «Поделиться» стала «В сторис» (`TestTags.RESULTS_SHARE`). Если игрока нет в списке партии (не должно случаться) — прежний текст |
| Android | Картинка пишется в `cache/story/` и отдаётся через `FileProvider` `${applicationId}.story` из манифеста `:composeApp` (во всех сборках); `<queries>` на `com.instagram.android`, чтобы увидеть Instagram на Android 11+ |
| iOS | `LSApplicationQueriesSchemes` = `instagram-stories` (иначе `canOpenURL` всегда «нет»); `NSPhotoLibraryAddUsageDescription`, потому что в системном меню с картинкой есть «Сохранить изображение», а без этой строки iOS закрывает приложение |

## Почему так

- **Без карты.** Треки и зона на картинке показывают двор, где играли, а часто — где живёт игрок. Сторис видят посторонние. Записи и повтор партии остаются только для её игроков (ADR 0011).
- **Только свои награды.** Ники других игроков — их данные; они не соглашались попасть в чужую сторис.
- **Рисуем в приложении.** Сервер не знает, как игрок хочет поделиться, и не должен хранить картинки. Всё, что нужно, уже есть в последнем снимке игры.
- **Прямо в Instagram — по возможности.** Без ID Meta всё работает через системное меню; когда ID появится, достаточно передать свойство в CI, код менять не нужно.

## Что дальше

- Завести приложение в Meta for Developers и передать `hovanki.facebookAppId` в `preview.yml` и `release.yml`.
- Проверить на телефонах: Android с Instagram и без, iPhone с Instagram и без, «Сохранить изображение» на iPhone.
- Варианты картинки (наклейка поверх фото, другие фоны, без водяного знака за премиум) — после проверки и решения по монетизации (ADR 0023).
